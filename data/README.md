# Data

The dataset used in this project is derived from the European Soccer Database available through Kaggle.

The original dataset contains historical football match and team information used for data analysis, feature engineering, and machine learning-based match outcome prediction.

## Data Source

European Soccer Database by Hugo Mathien:

https://www.kaggle.com/datasets/hugomathien/soccer

## Data Preparation

The raw database was processed before being used for modelling. The project includes data loading, cleaning, feature engineering, and preprocessing steps implemented in the Python modules in the `scripts/` directory.

The raw database files are not included in this repository due to their size. Users who wish to reproduce the analysis should obtain the original dataset from the source above and follow the preprocessing pipeline provided in this repository.
